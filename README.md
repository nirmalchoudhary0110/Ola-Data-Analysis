# 🚖 OLA Data Analyst Project

## 📘 Project Overview
The **OLA Data Analyst Project** focuses on performing **data analysis** for ride-booking data from OLA Cabs using **SQL** and **Power BI**.  
This project demonstrates real-world data analytics skills such as:
- Querying databases using SQL  
- Generating business insights from ride data  
- Building interactive Power BI dashboards for visualization  

---

## 🎯 Objectives
1. Analyze ride-booking data to extract key business insights.  
2. Identify patterns in customer behavior, driver ratings, and cancellations.  
3. Build visual reports showing trends in ride volume, cancellations, and revenues.  
4. Practice SQL query writing and Power BI dashboard design.
